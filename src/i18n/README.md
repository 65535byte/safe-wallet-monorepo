# Web 国际化

参考 `safe-wallet-monorepo/apps/web/src/i18n`：未保存手动选择时跟随系统语言，中文使用 `zh-CN`，其他或无法识别时使用英文，支持英文（`en`），语言保存在 `8379.language`。顶部菜单切换后刷新当前 URL，确保模块级文案、校验消息、查询缓存和页面使用同一种语言。存储失败时保留原语言并通过消息提示反馈。

- 文案资源：`locales/zh-CN.json`、`locales/en.json`。两套资源必须有相同的键和插值参数。
- 使用 `translateMessage("message.key", { name: value })`；完整句子优先使用一条资源，避免依赖中文语序拼接英文。
- 展示日期使用 `formatDate`。协议里的 ISO 时间和 App 分享时间保持原格式。
- 品牌、地址、Token 符号、金额、用户输入的账户/签名人名称及 API 原始返回值不参与翻译。
- 交易弹窗、签名/执行中、创建/导入异步处理中禁止切换语言，避免刷新中断操作。
- HTTP 错误判断依据结构化状态和服务端响应，不依据翻译后的文案。

`npm test` 包含双语资源检查、页面渲染、存储异常、日期格式和协议数据不变性测试。新增文案同时维护两份资源。
