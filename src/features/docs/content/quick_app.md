### 8379“添加到桌面”功能使用指南

#### 问题现象
部分用户在8379客户端页面内点击“添加到桌面”后，手机桌面上找不到对应图标。

#### 根本原因
8379内“添加到桌面”功能被系统关闭。需要前往手机系统设置中，为8379打开“创建桌面快捷方式”开关。开启后，请返回8379重新点击“添加到桌面”。

#### 各主要机型设置路径

#### 华为
- 方式1：设置 → 应用和通知 → 权限管理 → 权限 → 创建桌面快捷方式 → 8379
- 方式2：设置 → 应用和通知 → 应用管理 → 8379 → 权限 → 设置单项权限 → 创建桌面快捷方式
- 方式3：手机管家 → 权限管理 → 权限 → 创建桌面快捷方式 → 8379

#### OPPO
- 方式1：设置 → 安全 → 应用权限 → 权限 → 创建桌面快捷方式 → 8379
- 方式2：手机管家 → 权限隐私 → 应用权限管理 → 权限 → 创建桌面快捷方式 → 8379

#### vivo
- 方式1：设置 → 更多设置 → 权限管理 → 权限 → 桌面快捷方式 → 8379
- 方式2：i管家 → 应用管理 → 权限管理 → 桌面快捷方式 → 8379

#### 小米
- 方式1：设置 → 授权管理 → 应用权限管理 → 权限管理 → 桌面快捷方式 → 8379
- 方式2：安全中心 → 应用管理 → 权限 → 应用权限管理 → 权限管理 → 桌面快捷方式 → 8379

#### 操作示例（以华为手机为例）
1.打开手机“设置”

![设置](https://wallet.8379hk.com/static/quick/image.png)

2.进入“应用和服务”

![应用和服务](https://wallet.8379hk.com/static/quick/image-1.png)

3.进入“权限管理”，找到“创建桌面快捷方式”

![alt text](https://wallet.8379hk.com/static/quick/image-2.png)

4.进入该选项，找到“8379”，打开其开关

![alt text](https://wallet.8379hk.com/static/quick/image-3.png)

5.重新回到8379客户端内，选择“添加到桌面”
